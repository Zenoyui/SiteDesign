# Конструктор макетов

Страница, которая помогает придумать и собрать печатный макет, даже если пока непонятно, чего хочется.

**Левая половина** ведёт по шагам: на каждом шаге формальный вопрос и готовые варианты ответа
(это не чат-бот). **Правая половина** показывает сам макет, его стороны и то, как он будет выглядеть в жизни.

Внешний вид самой страницы нарочно простой, как документ Word: белый лист, Times New Roman,
таблицы с тонкой чёрной рамкой и серой шапкой.

## Шаги

1. **Идея**: что делаем, зачем и **в какой сфере** (12 сфер: транспорт, еда, кофейни, доставка, магазин, красота, образование, события, финансы/IT, эко, детям, премиум).
2. **Формат**: A3, A4, A5, A6, евро (DL), квадрат, слайд 16:9; ориентация; количество сторон.
3. **Стиль**: разбор шести компаний, любой набор из них смешивается:
   | Стиль | Похоже на | Приём |
   |---|---|---|
   | Поисковый | Яндекс | белый воздух, красный круг-акцент |
   | Поездочный | Яндекс Go | жёлтая плашка, чёрные кнопки-«таблетки» |
   | Полосатый | Whoosh | мягкая жёлтая полоса-маркер, графит |
   | Фиолетовый | Юрент | фиолетовые градиентные пятна |
   | Пламенный | Burger King | волна снизу, кремовый фон, капс |
   | Точечный | Вкусно — и точка | тёмно-зелёный, оранжевая точка и тире |
4. **Сочетание**: варианты смешения выбранных стилей.
5. **Цвета**: палитры для выбранной сферы по психологии цвета, справочник «что чувствует покупатель», палитры стилей, проверка контраста.
6. **Текст**: поля и идеи заголовков.
7. **Внимание**: приёмы маркетинга, включаются в любых сочетаниях —
   срочность, три выгоды со значками, цена-якорь, социальное доказательство, гарантия, стрелка к кнопке, самая контрастная кнопка;
   плюс справочник принципов (3 секунды, AIDA, Z-паттерн, эффект изоляции, 60-30-10, правило трёх, Чалдини и др.).
8. **Расположение**: шесть раскладок.
9. **Детали**: декор, кнопка, бейдж, контакты, QR-код, картинка, шрифт, скругления.
10. **Эффекты и значки**: «фирменные штучки» брендов, берутся целиком или смешиваются —
    | Стиль | Эффекты | Значки | Узор | Показ продукта |
    |---|---|---|---|---|
    | Поисковый | мягкая тень, матовое стекло | в светлом кружке | сетка, как на карте | карточка |
    | Поездочный | мягкая тень | в залитом круге | шашечки | экран приложения |
    | Полосатый | жёсткая тень-сдвиг | в квадрате | диагональные полосы | экран приложения |
    | Фиолетовый | градиент, свечение | в светлом кружке | конфетти | экран приложения |
    | Пламенный | наклейка, наклон, зерно печати | жирные | растровые точки | значок-наклейка |
    | Точечный | плоско | в кольце | ровные точки | фото или значок в круге |
11. **Редактор**: мини-Figma (см. ниже).
12. **Результат**: сводка и скачивание.

Кнопка «Случайная идея» сама подбирает комбинацию ответов.

### Почему «похоже», а не копия
Логотипы, названия и фирменные шрифты не используются. Цвета сдвинуты на несколько градусов оттенка,
вместо фирменных шрифтов взяты свободные из Google Fonts (Onest, Manrope, Unbounded, Rubik, Nunito, Montserrat).
Берутся только приёмы: логика цвета, формы, характер типографики.

## Редактор (как в Figma)

- выделение кликом, Shift+клик, рамкой; слои с видимостью, блокировкой и перетаскиванием порядка;
- перемещение с **умными направляющими** (края и центры листа, поля, другие элементы), Ctrl отключает прилипание;
- изменение размера за 8 ручек (Shift сохраняет пропорции, Alt меняет от центра), поворот за кружок (Shift даёт шаг 15°);
- **ограничения** (Constraints): слева / справа / слева и справа / по центру / масштаб; работают при смене формата листа;
- **привязка к другому элементу**: элемент ездит за целью с заданным смещением (так кнопка держит свой текст);
- фигуры: прямоугольник, эллипс, линия, звезда-бейдж, волна, текст, картинка, QR-код, значок (26 штук, 6 стилей), узор, телефон;
- эффекты любого элемента: мягкая и жёсткая тень, свечение, градиент, обводка, скругления, прозрачность; у текста — обводка букв, зачёркивание, плашка; у страницы — зерно печати;
- текст редактируется двойным кликом прямо на листе; шрифт, начертание, кегль, интерлиньяж, трекинг, выключка;
- выравнивание и распределение, дублирование, копирование и вставка (в том числе картинок из буфера), перетаскивание файла на лист;
- отмена и повтор, масштаб колесом с Ctrl, перемещение по холсту с пробелом;
- несколько страниц или сторон.

## Скачивание

PDF для печати (точный размер, по желанию вылеты 3 мм и метки реза), печать из браузера, PNG, JPG,
PowerPoint (.pptx), HTML-презентация одним файлом, файл проекта (.json), который можно открыть позже.
Разрешение 150, 300 или 600 dpi.

## Запуск

Сборка не нужна: это обычные HTML, CSS и JS. Откройте `index.html` через любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

### Публикация на GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`, который выкладывает сайт при каждом push.
Нужно один раз:

1. Если репозиторий приватный и аккаунт бесплатный — сделать его публичным (Settings → General → Danger Zone → Change visibility). Pages для приватных репозиториев есть только в GitHub Pro.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Actions → «Публикация на GitHub Pages» → Run workflow (или просто сделать любой push).

Адрес сайта: `https://zenoyui.github.io/SiteDesign/`
Для шрифтов, PDF и PPTX нужен интернет: библиотеки грузятся с cdnjs и jsDelivr по мере надобности.

## Структура

```
index.html        разметка: левая и правая половины
css/app.css       оформление «как docx»
js/util.js        цвета, геометрия, DOM-помощники
js/brands.js      разбор стилей, форматы, виды продуктов, тексты-примеры
js/render.js      отрисовка страницы на canvas (одна для редактора, превью и экспорта)
js/generator.js   сборка макета из ответов
js/app.js         состояние, история, ограничения, привязки
js/editor.js      мини-Figma: мышь, клавиатура, направляющие
js/panel.js       панель свойств и слои
js/wizard.js      шаги с вопросами
js/views.js       вкладки страниц и виды справа
js/export.js      PDF, PNG/JPG, PPTX, HTML, печать, проект
js/main.js        запуск
```

## Тесты

```bash
python3 -m http.server 8765 &
node tests/styles.test.js
node tests/marketing.test.js
```

- `styles.test.js` — все 63 набора стилей дают разные превью, каждый стиль участвует в смеси, клики меняют картинку.
- `marketing.test.js` — каждый приём внимания появляется во всех раскладках; со всеми приёмами текст не вылезает за лист (A6, A4, DL, слайд);
  каждый эффект заметен и все пары эффектов смешиваются; стили значков, узоры, показ продукта, наборы брендов и сферы работают;
  все 12 шагов открываются без ошибок, клики на шагах «Внимание» и «Эффекты» меняют превью.
